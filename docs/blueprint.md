# **App Name**: AttendaVision

## Core Features:

- Image Capture: Capture images via the device's camera for attendance tracking.
- Attendance Record: Automatic logging of attendance records with timestamps.
- User Interface: Simple and intuitive user interface for easy navigation and use.
- Student Scan QR: Students scan QR code to mark attendance (mobile-friendly)
- Attendance History: View personal attendance history
- Low Attendance Notification: Get notifications for low attendance
- QR Code Generation: Generate unique QR codes for each class
- QR Code Expiration: Set expiration time (5-60 minutes)
- Real-time Dashboard: Real-time dashboard with Today's attendance percentage, Student-wise attendance reports, Weekly/monthly trends, Export to Excel/PDF

## Style Guidelines:

- Primary color: Deep sky blue (#42A5F5), suggesting intelligence and trustworthiness.
- Background color: Light cyan (#E1F5FE), a very desaturated version of the primary, which provides a clean, calm backdrop.
- Accent color: Dodger blue (#1E88E5), a darker analogous color used for actionable items.
- Body and headline font: 'Inter', sans-serif, for a modern and objective feel.
- Simple, outline-style icons for clarity and ease of understanding.
- Clean and spacious layout with clear visual hierarchy to guide the user.
- Subtle animations to provide feedback and enhance user experience, like a pulse when attendance is successfully recorded.
